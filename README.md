An enterprise-grade, agentless observability landing platform and interactive telemetry sandbox built for the **Acdyon Technologies Frontend Challenge (Track 2: The Premium Home Page)**.

Features real-time 3D WebGL parametric vertex shaders reacting to simulated network entropy, multi-region synthetic probe inspection, instant 5xx outage / latency injection micro-interactions, flawless responsive layout (390px - 1440px+), and high-contrast Light/Dark mode parity.

---

## 🌟 Key Features

1. **Agentless Synthetic Health Probing**
   - Live interactive sandbox inspecting microsecond endpoint latencies, SLA history sparklines, and real-time audit event streams without heavy agent daemons.
2. **Interactive 3D WebGL Engine (`Three.js / React Three Fiber`)**
   - Parametric vertex shader modulations reacting dynamically to network load factor sliders.
   - Switchable 3D topologies: **Quantum Sphere** and **Torus Knot**.
   - Hardware-accelerated GPU rendering decoupled from main thread React state.
3. **Micro-Interactions & Stress Simulations**
   - **Inject Latency**: Triggers synthetic latency spikes (>800ms) with degraded SLA warnings.
   - **Force 500 Outage**: Simulates critical HTTP 500 errors across monitored endpoints.
   - **Inject Matrix Overload Stress**: Warps 3D WebGL meshes and updates token velocity metrics in real-time.
   - **Konami Code Easter Egg**: Press `↑ ↑ ↓ ↓ ← → ← → B A` on your keyboard to unlock root compute telemetry.
4. **All-or-Nothing Dark & Light Mode System**
   - Unified color token engine guaranteeing high contrast text and pristine accessibility in both light (`#f8faff`) and dark (`#0b0f19`) themes.
5. **Zero Fake Marketing**
   - Strictly honest engineering copy with zero fake logos, zero fabricated testimonials, and zero artificial user metrics.

## 🚀 Quick Start & Local Setup

### Prerequisites
- Node.js `18.x` or higher
- npm `9.x` or higher

### Installation

```bash
# Clone the repository
git clone https://github.com/rishabhtcodes/devtelemetry.git

# Change directory
cd devtelemetry

# Install dependencies
npm install

# Start local Vite development server
npm run dev
```

The application will be running locally at `http://localhost:5173`.
